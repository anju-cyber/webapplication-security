# Nmap Learning Notes

This repository contains my practical notes while learning **Nmap**.

The objective of this repository is to understand how Nmap is used during the reconnaissance and enumeration phase of a penetration test.

> All scans were performed in my local lab environment on **Metasploitable2** for educational purposes only.
